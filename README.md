Стартиране на проекта
За да стартирате проекта, първо трябва да имате инсталиран Visual Studio 2022 и необходимата .NET SDK версия.

Отворете файла с разширение .sln чрез Visual Studio.

Изчакайте проектът да се зареди и всички NuGet зависимости да бъдат възстановени.

В Solution Explorer изберете проекта, който искате да стартирате, и натиснете Set as Startup Project.

Компилирайте проекта чрез Build → Build Solution или клавишната комбинация Ctrl + Shift + B.

Стартирайте приложението с F5 (с Debugging) или Ctrl + F5 (без Debugging).

С вход "Ани" трябжа да се изведе "Добър ден, Ани"
С три интервала извежда ""Моля, въведете име.""
